# bmp581 handler

BMP581 barometric pressure sensor on I2C or SPI, through `kb::handlers::bmp581::Handler<Bus>`
(`kb/handlers/bindings/bmp581.hpp`, driver `driver-bmp581` at the pin in `components/drivers/drivers.lock.yml`).

## What it gives the application

| Kind | Name | What |
| --- | --- | --- |
| Snapshot | `Snapshot` | `pressure_raw` (1/64 Pa), `temperature_raw` (1/65536 degC), `pressure_pa`, `temperature_c`, `forced` |
| Command | `MeasureOnce(io, timeout)` | One forced measurement now (standby mode), in the chip's units |
| Command | `ReadPressurePa(io, timeout)` | The pressure in pascals of a forced measurement now |
| Command | `SetPowerMode(io, mode, timeout)` | Standby, Normal or Continuous |
| Command | `CheckForReset(io, timeout)` | Finds out whether the chip reset since the start; a reset faults the handler |
| Command | `Command{Op::...}` with `Request()` | Data registers, interrupt status, FIFO count, raw register, latch clear |

`io` is either facade; the calls are the same on an owner bus and on a guarded bus.

**Transports.** `Handler<Bus>` picks its port from the bus type: a `kb::iface::I2cBus` gives `I2cPort<Bus>`
(address from `Config::address`, with `GetLastFailure` so an absent chip is `NoDevice`), a
`kb::iface::SpiDevice` gives `SpiPort<Dev>` (four-wire; the driver sends the frame that selects SPI itself).
`kBus` follows, so the handler sits on a `BusDomain` of the matching kind.

**Samples.** `Measure()` runs a forced measurement when the configured mode is standby, and reads the data
registers in normal and continuous mode (`NoData` until the first conversion counts as a failure, so start
sampling after one data-rate period). `Config::sample_verify` reads the data twice.

The port's `DelayUs` goes through the hook timing: a spin on the HAL's busy-wait below 1 ms, a
`kb::rtos::SleepFor` (at least the time asked) from 1 ms.

## Thread model

`kRequiresOwner = false`. A pressure sensor is slow and read now and then, often from several tasks, so a
guarded bus (`BusDomain<Bus, ThreadModel::Guarded>` with `Guarded<Handler>`) is the usual choice; on an
owner bus the owner task samples every `sample_period` and other tasks read `Latest()`.

## Start-up

| Stage | Kinds | Mode | Driver call | Deadline |
| --- | --- | --- | --- | --- |
| 0 | `Identify + Configure` | sync | `EnsureInitialized()`: power-up wait, soft reset, CHIP_ID, NVM ready, INT_STATUS checks, configuration written and read back, configured mode entered (about 7 ms) | `Config::start_deadline` |

The chip has no reset pin and its supply is the board's, so there is no `Power` or `HostReset` stage. On a
failure the report names stage 0 with the driver's error in `detail`; the next `EnsureStarted()` starts again.

## Health

| Driver error | kb::Status | Effect |
| --- | --- | --- |
| `DeviceReset`, `NotInitialized` | `NotReady` | Faulted at once (the chip reset; only a new start configures it) |
| `StateUnknown` | `Fault` | Faulted at once (a failed write left the configuration in doubt; only a new start clears it) |
| `NoData` | `NotReady` | Counts toward `fault_after` (no measurement since the reset) |
| `Bus`, `InvalidReply` | `BusError` | Counts toward `fault_after` (a failed transfer, or a reply the chip cannot send) |
| `NoDevice` | `NoDevice` | Counts toward `fault_after`; at start-up the start fails |
| `OutOfRange` | `OutOfRange` | Counts toward `fault_after` |
| `DeviceIdMismatch`, `DeviceFault`, `WriteMismatch`, `ConfigRejected` | `Fault` | Counts toward `fault_after` |
| `InvalidArgument`, `Timeout`, `Busy`, `Unsupported` | the same name | `InvalidArgument` is refused (recorded, not counted); the others count toward `fault_after` |
| `Crc` | `CrcMismatch` | Not returned by the driver |

Recovery is the generic plan: `Deinitialize()` (a soft reset into deep standby), then the start-up again.

## Example

```cpp
using Bus = board::I2c0;                                          // a kb::iface::I2cBus
using Baro = kb::handlers::bmp581::Handler<Bus>;
kb::handlers::BusDomain<Bus, kb::handlers::ThreadModel::Guarded> i2c0{bus};
kb::handlers::Guarded<Baro, decltype(i2c0)> baro{i2c0, bus, timing, config};

static_cast<void>(i2c0.Create());
static_cast<void>(baro.Create());
if (baro.EnsureStarted(kb::Milliseconds{50U}).IsOk()) {
  const auto s = baro.Sample(kb::Milliseconds{50U});              // forced in standby mode
  const kb::Result<float> pa = kb::handlers::bmp581::ReadPressurePa(baro, kb::Milliseconds{50U});
}
```

Tests: `tests/integration/bmp581/` (the driver's register model behind a `kb::iface::I2cBus` and a
`kb::iface::SpiDevice`, both thread models).
