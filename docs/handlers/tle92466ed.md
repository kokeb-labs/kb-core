# tle92466ed handler

TLE92466ED six-channel solenoid current controller on SPI, through `kb::handlers::tle92466ed::Handler<Dev>`
(`kb/handlers/bindings/tle92466ed.hpp`, driver `driver-tle92466ed` at the pin in `components/drivers/drivers.lock.yml`).

## What it gives the application

| Kind | Name | What |
| --- | --- | --- |
| Snapshot | `Snapshot` | `status` (FB_STAT, decoded), `enabled` (EN_CH bits), `dropped` (channels the chip switched off), `mission` |
| Command | `EnterMissionMode(io, timeout)` | Mission Mode, when the entry conditions hold: the enabled channels switch |
| Command | `EnterConfigMode(io, timeout)` | Config Mode: every channel off |
| Command | `SetEnabledChannels(io, mask, timeout)` | The channels in `mask` on, the others off |
| Command | `DisableChannel(io, channel, timeout)` | One channel off, in any state |
| Command | `SetCurrent(io, channel, microamps, timeout)` | The average current setpoint; returns what was programmed |
| Command | `ReadCurrent(io, channel, timeout)` | The average current of the last measurement period |
| Command | `ReadFaults(io, timeout)`, `ClearFaults(io, timeout)` | The nine diagnosis registers; clear them on the chip |
| Command | `Command{Op::...}` with `Request()` | Enable one channel, all off, watchdog reload, DRV pins, supply, FAULTN, raw register, record clear |

`io` is either facade; the calls are the same on an owner bus and on a guarded bus.

**Pins.** `Config::outputs` holds RESN (`kPinReset`, wire it active low), EN (`kPinEnable`), DRV0 and DRV1
(`kPinDrv0`, `kPinDrv1`); `Config::inputs` holds FAULTN (`kPinFault`, open drain: wire it active low). A pin
the board does not wire is left absent: driving it succeeds without doing anything, as the driver expects
(RESN pulled up, EN tied high, DRVx tied low). The port's first bring-up drives every wired output to its
idle level (RESN in reset, EN and DRVx low) before the first transfer.

**Samples.** `Measure()` reloads the SPI watchdog when `chip.spi_watchdog` is on, then reads FB_STAT. A
POR or RES event in that FB_STAT, while the driver's reset watch is armed, is reported as `UnexpectedReset`:
the status read returns the register as data, so the handler applies the driver's own reset rule to it.

**Safety.** The handler only reports. A Faulted health record does not switch any output; on a reset or a
critical fault the driver itself drives EN low and stops. `Recover()` and `Stop()` call `Deinitialize()`
(Config Mode, every channel off, EN low) before the plan runs again, and every start ends in Config Mode. A
safety layer must reach its safe state without any handler call succeeding (ADR-0011).

The port's `DelayUs` goes through the hook timing: a spin on the HAL's busy-wait below 1 ms, a
`kb::rtos::SleepFor` (at least the time asked) from 1 ms.

## Thread model

`kRequiresOwner = false`. Commanded valves used from a control task suit a guarded bus. With the SPI
watchdog on (`chip.spi_watchdog`), the chip needs a reload within `chip.watchdog_reload`: put it on an owner
bus with a `sample_period` well below the watchdog time, so the owner task feeds the watchdog with every
sample; on a guarded bus the application must call `Sample()` (or `Op::ReloadWatchdog`) at that rate.

## Start-up

| Stage | Kinds | Mode | Driver call | Deadline |
| --- | --- | --- | --- | --- |
| 0 | `Identify + Configure` | sync | `EnsureInitialized()`: reset (RESN pulse, or CH_CTRL 0 and t_POR without RESN), INIT_DONE polled (`chip.init_timeout_us`), ICVID, diagnosis kept and cleared, every register written, SPI watchdog last; ends in Config Mode | `Config::start_deadline` |

The driver drives RESN and EN itself, so there is no `HostReset` or `Power` stage. On a failure the report
names stage 0 with the driver's error in `detail`; the next `EnsureStarted()` starts again.

## Health

| Driver error | kb::Status | Effect |
| --- | --- | --- |
| `UnexpectedReset`, `NotInitialized` | `NotReady` | Faulted at once (POR or RES event: every register lost, EN low) |
| `CriticalFault` | `Fault` | Faulted at once (the chip is in its Critical Fault state; RESN or a power cycle leaves it) |
| `NotReady` | `NotReady` | Counts toward `fault_after` (no new feedback values) |
| `Bus`, `ReplyMismatch`, `FrameRejected` | `BusError` | Counts toward `fault_after` |
| `Crc` | `CrcMismatch` | Counts toward `fault_after` |
| `NoDevice` | `NoDevice` | Counts toward `fault_after`; at start-up the start fails; the first empty reply after a reset |
| `WrongState` | `Busy` | Counts toward `fault_after`; nothing sent, the call needs the other mode |
| `DeviceIdMismatch`, `DeviceFault`, `MissionBlocked`, `WriteMismatch` | `Fault` | Counts toward `fault_after` |
| `InvalidArgument`, `Timeout`, `Unsupported` | the same name | `InvalidArgument` is refused (recorded, not counted); the others count toward `fault_after` |
| `Busy` | `Busy` | Not returned by the driver |

Recovery is the generic plan: `Deinitialize()`, then the start-up again, whose RESN pulse also leaves the
Critical Fault state.

## Example

```cpp
using Dev = board::Spi4Icc;                                       // a kb::iface::SpiDevice, mode 1
using Icc = kb::handlers::tle92466ed::Handler<Dev>;
namespace icc = kb::handlers::tle92466ed;
kb::handlers::BusDomain<Dev, kb::handlers::ThreadModel::Guarded> spi4{dev};
icc::Config config{};
config.chip.channels[0] = tle92466ed::CurrentControlChannel();
config.outputs[icc::kPinReset].pin.emplace(resn_pin);
config.outputs[icc::kPinReset].active_low = true;
kb::handlers::Guarded<Icc, decltype(spi4)> io{spi4, dev, timing, config};

static_cast<void>(spi4.Create());
static_cast<void>(io.Create());
if (io.EnsureStarted(kb::Milliseconds{100U}).IsOk()) {
  static_cast<void>(icc::SetCurrent(io, tle92466ed::Channel::Ch0, 500'000U, kb::Milliseconds{5U}));
  static_cast<void>(icc::EnterMissionMode(io, kb::Milliseconds{5U}));
  static_cast<void>(icc::SetEnabledChannels(io, 0x01U, kb::Milliseconds{5U}));
}
```

Tests: `tests/integration/tle92466ed/` (the driver's chip model behind a `kb::iface::SpiDevice` and kb GPIO
pins, both thread models, the SPI watchdog fed by an owner task).
