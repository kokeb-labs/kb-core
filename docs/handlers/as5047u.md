# as5047u handler

AS5047U 14-bit magnetic angle encoder on SPI, through `kb::handlers::as5047u::Handler<Dev>`
(`kb/handlers/bindings/as5047u.hpp`, driver `driver-as5047u` at the pin in `components/drivers/drivers.lock.yml`).

## What it gives the application

| Kind | Name | What |
| --- | --- | --- |
| Snapshot | `Snapshot` | `angle_counts`, `velocity_counts` (with `sample_velocity`), `agc` and `magnitude` (with `sample_field`), `latched_errfl`, `flags_lost` |
| Command | `ReadAngle(io, timeout)` | The angle in counts (0 to 16383), read now |
| Command | `ReadVelocity(io, timeout)` | The signed velocity in counts (24.141 deg/s per count), read now |
| Command | `SetZeroHere(io, timeout)` | The current position reads 0 from now on; returns the new zero position |
| Command | `SetDirection(io, direction, timeout)` | The direction in which the angle increases |
| Command | `CheckForReset(io, timeout)` | Compares the settings registers with what the driver wrote; a reset faults the handler |
| Command | `ReadErrorFlags(io, timeout)` | ERRFL (raw), which the read clears on the chip |
| Command | `Command{Op::...}` with `Request()` | AGC, magnitude, DIA, zero position, latch clear, raw register read and write |

`io` is either facade; the calls are the same on an owner bus and on a guarded bus. The OTP burn
(`ProgramOtp()`) is not a command: it cannot be undone and belongs in a production tool.

The port's `DelayUs` goes through the hook timing: a spin on the HAL's busy-wait below 1 ms, a
`kb::rtos::SleepFor` (at least the time asked) from 1 ms.

## Thread model

`kRequiresOwner = false`. An encoder is read at the control rate, so the owner model is the usual
choice: the owner task samples the angle (and velocity) every `sample_period` and every other task
reads `Latest()` without a lock, with the sequence and age of the sample. A guarded bus works for a
slow position readout used from several tasks.

## Start-up

| Stage | Kinds | Mode | Driver call | Deadline |
| --- | --- | --- | --- | --- |
| 0 | `Identify + Configure` | sync | `EnsureInitialized()`: DIA polled until the magnetic loops settle (`chip.startup_timeout_ms`), ERRFL cleared, every setting written and read back | `Config::start_deadline` |

The chip has no reset or enable pin, so there is no `Power` or `HostReset` stage. On a failure the
report names stage 0 with the driver's error in `detail`; the next `EnsureStarted()` starts again.

## Health

| Driver error | kb::Status | Effect |
| --- | --- | --- |
| `DeviceReset`, `NotInitialized` | `NotReady` | Faulted at once (the chip reloaded its settings from the OTP) |
| `NotReady` | `NotReady` | Counts toward `fault_after`; at start-up the loops did not settle in time |
| `Bus`, `Framing`, `Command` | `BusError` | Counts toward `fault_after` |
| `Crc` | `CrcMismatch` | Counts toward `fault_after` |
| `NoDevice` | `NoDevice` | Counts toward `fault_after`; at start-up the start fails |
| `MagnetWarning` | `OutOfRange` | Counts toward `fault_after`: the field is out of range, the angle is not a measurement |
| `DeviceIdMismatch`, `DeviceFault`, `WriteMismatch`, `OtpVerify` | `Fault` | Counts toward `fault_after` |
| `InvalidArgument`, `Timeout`, `Busy`, `Unsupported` | the same name | `InvalidArgument` is refused (recorded, not counted); the others count toward `fault_after` |

Recovery is the generic plan: `Deinitialize()`, then the start-up again, which writes every setting.

## Example

```cpp
using Dev = board::Spi1Encoder;                                   // a kb::iface::SpiDevice, mode 1
using Enc = kb::handlers::as5047u::Handler<Dev>;
kb::handlers::BusDomain<Dev, kb::handlers::ThreadModel::Owner> spi1{dev};
kb::handlers::OwnerAccess<Enc, decltype(spi1)> enc{spi1, dev, timing, config};

static_cast<void>(enc.Create());
enc.RequestStart();                                              // the owner task runs the plan
// owner task, every control step: static_cast<void>(spi1.Service(kb::rtos::Now(), enc));
const auto snap = enc.Latest();                                  // any task, lock-free
if (snap.IsOk()) {
  const uint16_t angle = snap.Value().value.angle_counts;
}
```

Tests: `tests/integration/as5047u/` (the driver's frame-level chip model behind a `kb::iface::SpiDevice`, both
thread models).
