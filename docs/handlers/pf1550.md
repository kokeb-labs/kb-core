# pf1550 handler

PF1550 power management IC (three bucks, three LDOs, a linear charger, an interrupt controller) on I2C, through
`kb::handlers::pf1550::Handler<Bus>` (`kb/handlers/bindings/pf1550.hpp`, driver `driver-pf1550` at the pin in
`components/drivers/drivers.lock.yml`).

## What it gives the application

| Kind | Name | What |
| --- | --- | --- |
| Snapshot | `Snapshot` | `charger` (state, battery, VBUS flags, classified fault), `state` (STATE_INFO), `events` (status bits latched by any call), `intb_asserted` and `has_intb` |
| Command | `SetChargerMode(io, mode, timeout)` | Charger off, linear only, or charge (only with limits-covered registers and no fault) |
| Command | `RestartCharger(io, timeout)` | Leave a latched charger fault state |
| Command | `ServiceChargerWatchdog(io, timeout)` | Clear the charger watchdog |
| Command | `ServiceInterrupts(io, timeout)` | Read and clear the interrupt status; returns the events |
| Command | `ReadRail(io, rail, timeout)` | One rail as the chip holds it |
| Command | `SetRailVoltage(io, rail, uv, timeout)` | An LDO or a DVS buck to a voltage inside its `Limits` window |
| Command | `RequestStandby(io, standby, timeout)` | Drive the STANDBY pin |
| Command | `SelfCheck(io, timeout)` | Identity, state Run, rails as configured, no latched fault, the input limit |
| Command | `Command{Op::...}` with `Request()` | Rail enables, interrupt masks, cancel a shutdown request, read one register |

`io` is either facade; the calls are the same on an owner bus and on a guarded bus. `EnterShip()` and
`EnterCoreOff()` cut the system's supplies and take confirmation tokens; they are not handler commands.

## Thread model

`kRequiresOwner = false`, guarded by preference. A power IC is slow and used sporadically from several tasks: the
power manager changes rails, a charger policy task sets the mode and services the watchdog, and the task an INTB
interrupt notifies calls `ServiceInterrupts()` (the ISR never calls the handler). A guarded bus
(`BusDomain<Bus, ThreadModel::Guarded>` with `Guarded<Handler>`) serves all of them with bounded locks. On an owner bus
the owner task reads the status every `sample_period` instead.

## Start-up

| Stage | Kinds | Mode | Driver call | Deadline |
| --- | --- | --- | --- | --- |
| 0 | `Identify` | sync | `EnsureInitialized()`: configuration check, DEVICE_ID, option, the charger as found against `Limits` | `Config::identify_deadline` |
| 1 | `Configure` | sync | `Configure()`: rails in `rail_order`, power control, power-down order, masks, the charger last | `Config::configure_deadline` |

The chip has no reset pin; STANDBY is a run-time state the application requests, not a start-up stage. On a failure
the report names the stage with the driver's error in `detail`; the next `EnsureStarted()` starts again from stage 0.

## Health

| Driver error | kb::Status | Effect |
| --- | --- | --- |
| `DeviceReset`, `NotInitialized` | `NotReady` | Faulted at once (the chip lost the registers the driver wrote) |
| `Refused` | `NotReady` | Counts toward `fault_after` |
| `Bus` | `BusError` | Counts toward `fault_after` |
| `NoDevice` | `NoDevice` | Counts toward `fault_after`; at start-up the start fails |
| `OutOfLimits` | `OutOfRange` | Counts toward `fault_after` (nothing was sent) |
| `Unsafe`, `InvalidArgument` | `InvalidArgument` | Refused: recorded as the last error, not counted against the chip (a caller's mistake) |
| `ReadOnlyRail`, `Unsupported` | `Unsupported` | Counts toward `fault_after` |
| `DeviceIdMismatch`, `DeviceFault`, `ChargerFault`, `VerifyFailed` | `Fault` | Counts toward `fault_after` |
| `Timeout`, `Crc`, `Busy` | `Timeout`, `CrcMismatch`, `Busy` | Counts toward `fault_after` |

Recovery is the generic plan: the driver is destroyed (it has no `Deinitialize()`), then both stages run again, which
writes the whole configuration.

## Example

```cpp
using Bus = board::I2c0;                                          // a kb::iface::I2cBus
using Pmic = kb::handlers::pf1550::Handler<Bus>;
kb::handlers::BusDomain<Bus, kb::handlers::ThreadModel::Guarded> i2c0{bus};
kb::handlers::Guarded<Pmic, decltype(i2c0)> pmic{i2c0, bus, timing, config};   // config.intb, config.standby

static_cast<void>(i2c0.Create());
static_cast<void>(pmic.Create());
if (pmic.EnsureStarted(kb::Milliseconds{50U}).IsOk()) {
  static_cast<void>(kb::handlers::pf1550::SetChargerMode(pmic, pf1550::ChargerMode::Charge, kb::Milliseconds{10U}));
  const auto events = kb::handlers::pf1550::ServiceInterrupts(pmic, kb::Milliseconds{10U});
}
```

Tests: `tests/integration/pf1550/` (the driver's register model behind a `kb::iface::I2cBus`, INTB and STANDBY as
kb pins, both thread models).
