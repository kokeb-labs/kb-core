# components/ports/esp32/examples/

ESP-IDF applications that use kb-core and this port, one per part or binding, each with its `sdkconfig.defaults`
(never a generated `sdkconfig`). Built in CI with ESP-IDF v5.5 (`ci-esp32.yml`). ESP-IDF code is allowed in an
example's own `main/` as well as in `../src/`.
