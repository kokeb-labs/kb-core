Detailed Description

The type-erased *Ref values of every kb::iface contract (ADR-0006 rule 5), in one header.

A *Ref is a non-owning value: a context pointer and a pointer to a constant table of function pointers, made from any type that satisfies the contract and itself static_asserted against it. It is how a HAL chooses an implementation at run time without a virtual function or a heap.

This header is kb-core's one recorded library deviation, DEV-KBC-004 (MISRA C++:2023 Rule 8.2.6): each table entry converts the void* context back to the type the table was built for. The conversion is confined here: the context and the table are set together by one constructor template constrained by the concept, and each constructor static_asserts that the table it takes was generated for the same type, so a context can only reach the functions of its own type.
