Detailed Description

Typed durations, the 64-bit monotonic instant, and wrap-safe elapsed-time arithmetic.

  • kb::Microseconds, kb::Milliseconds: durations as distinct types with a 32-bit count, so a millisecond value can never be passed where microseconds are expected. Conversions between them are explicit and round in the safe direction (ToMicroseconds saturates, ToMillisecondsCeil rounds up).
  • kb::Instant: a reading of the one 64-bit monotonic microsecond clock above the ports.
  • Elapsed time is always an unsigned subtraction (now - since), correct across a wrap of the counter. Timestamps are never compared with each other (no half-range compare): a deadline is "elapsed >= timeout".

There are no user-defined literals: write kb::Milliseconds{10U}.
