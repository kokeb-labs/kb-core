Detailed Description

kb::rtos::Thread<Derived, StackBytes>: the CRTP thread base (ADR-0006 register) with a static stack, a fixed-rate run loop, overrun counting, stop and park handling, a verified start and step and stack statistics.

A derived thread supplies three hooks, public or reachable by friendship:

Hook Called Returns
bool Setup() noexcept once, on the new thread false fails the start: the thread ends

Failed | | bool Step() noexcept | every period (or back to back with a zero period) | false ends the loop | | void Cleanup() noexcept | once, last, also after a failed Setup | - |

class Blinker : public kb::rtos::Thread<Blinker, 2048U> {
public:
bool Setup() noexcept { return true; }
bool Step() noexcept { led_.Toggle(); return true; }
void Cleanup() noexcept {}
};
Blinker blinker{}; // static, constexpr-constructed, no RTOS
call kb::rtos::ThreadConfig cfg{}; cfg.name = "blink"; cfg.period = kb::Milliseconds{500U}; if
(!blinker.Start(cfg).IsOk()) { ... } // after the scheduler runs

The constructor never touches the RTOS; Start() creates the thread and fails closed (AlreadyStarted, InvalidArgument, or the backend's status); StartAndWaitToVerify(config, timeout) also waits until Setup() has returned and fails closed when it failed (Fault) or did not return in time (Timeout). RequestStop() ends the loop after the current step; Join(timeout) waits for the end. RequestPark() parks the loop after the current step until Resume() (or ResumeFromIsr() from an interrupt handler); the period grid restarts on resume, so a long park is not counted as overruns. StackFreeBytes() is the stack's high-water mark where the backend measures it. No virtual function is involved: hooks are called through Derived.
