Detailed Description

Fixed-capacity FIFOs: RingBuffer<T, N> for one context, SpscRing<T, N> for one producer and one consumer in different contexts (a task and an interrupt). No heap, no lock.

  • RingBuffer: Push refuses when full, PushOverwrite drops the oldest element; Pop, Peek, PeekAt, Discard. Not safe for concurrent use: guard it, or use SpscRing.
  • SpscRing: wait-free TryPush (producer only) and TryPop (consumer only). Indices are free-running unsigned counters, so head - tail is the fill level across a wrap; N is a power of two. Uses only atomic loads and stores of std::size_t (acquire and release), which Cortex-M, RISC-V and x86 do natively.
