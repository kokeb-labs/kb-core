Detailed Description

kb::Result<T>: a value or a kb::Status, with a vendor detail code. No exceptions, no heap.

A result is made by its two factories and read by its accessors; it has no public data. The factories build a value-initialised object and then set its fields (Result r{}; r.error_ = e; return r;), the form the MISRA C++:2023 scan accepts for Rule 0.2.2 where an aggregate initialiser is not.

kb::Result<uint16_t> ReadId() noexcept {
if (!ready) { return kb::Result<uint16_t>::Failure(kb::Status::NotReady); }
return kb::Result<uint16_t>::Success(0x5A5AU);
}
