Detailed Description

template<InlineElement T, std::size_t N>
requires (IsPowerOfTwo(N))
class kb::utils::SpscRing< T, N >

A wait-free single-producer single-consumer FIFO of at most N elements.

TryPush may be called from one context only (for example an interrupt) and TryPop from one other context only (for example a task). Size() is exact in either of those two contexts and approximate anywhere else.

TElement type (InlineElement).
NCapacity, a power of two.
