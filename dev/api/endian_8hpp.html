Detailed Description

Big- and little-endian loads and stores, and bounded byte readers and writers.

  • LoadBe16(bytes), StoreLe32(value, bytes), ...: fixed-extent spans, so the length is checked at compile time. They do not depend on the host's byte order.
  • ByteReader and ByteWriter: a cursor over a span for frames of mixed fields. Every read and write is bounded; the first one that does not fit fails, changes nothing, and makes the cursor fail from then on (Ok() is false), so a frame can be parsed in a straight line and checked once at the end.
kb::utils::ByteReader reader{frame};
uint8_t id = 0U;
uint16_t raw = 0U;
const bool parsed = reader.ReadU8(id) && reader.ReadBe16(raw) && reader.AtEnd();
