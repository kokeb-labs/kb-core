Detailed Description

The clock and delay contracts: MonotonicClock (the one 64-bit microsecond clock above the ports) and BusyWait (short delays below one millisecond), with MonotonicClockRef and BusyWaitRef.

Concept Member Meaning
MonotonicClock kb::Instant Now() const noexcept Microseconds since an arbitrary start;

never goes back, never wraps in practice | | BusyWait | void WaitUs(kb::Microseconds us) noexcept | Spins for at least us; for waits below 1 ms (longer ones use kb::rtos::SleepFor) |

Driver hooks with a 32-bit clock narrow Now() with kb::utils::NarrowUs / NarrowMs and compare by unsigned elapsed time (kb::utils::ElapsedSince).
