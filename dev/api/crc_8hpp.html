Detailed Description

Table-driven, constexpr CRC-8, CRC-16 and CRC-32 in the Rocksoft parameter model.

Crc<T, Poly, Init, Reflected, XorOut> is one CRC: width from T (uint8_t, uint16_t or uint32_t), the normal (MSB-first) polynomial, the initial register, whether input and output are reflected (both or neither) and the final XOR. The 256-entry table is computed at compile time. Named presets below carry their catalogue check value (the CRC of "123456789"), which the tests assert.

const std::array<uint8_t, 2> word{0xBEU, 0xEFU};
const uint8_t crc = kb::utils::Crc8Sensirion::Compute(word); // 0x92
kb::utils::Crc32Ieee running{};
running.Update(first_half);
running.Update(second_half);
const uint32_t crc32 = running.Value();
