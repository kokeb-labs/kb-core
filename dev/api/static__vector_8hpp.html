Detailed Description

kb::utils::StaticVector<T, N>: a vector with a fixed capacity and inline storage. No heap.

Every operation that can fail (push into a full vector, index past the end) reports it with a [[nodiscard]] bool and changes nothing. Elements are value types (std::semiregular, trivially copyable), held in a std::array, so the vector itself is trivially copyable and constexpr.

kb::utils::StaticVector<uint8_t, 4> v{};
const bool pushed = v.PushBack(7U); // true
for (const uint8_t x : v) { ... }
