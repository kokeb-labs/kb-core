Detailed Description

template<typename T>
requires (ResultValue<T> || std::is_void_v<T>)
class kb::Result< T >

A value of type T, or the reason there is none.

Failure(Status::Ok) is a programming error; it is recorded as Status::Fault, so a failure can never read as a success.
