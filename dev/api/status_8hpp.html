Detailed Description

kb::Status, the one error vocabulary of kb-core, and its names.

Every kb-core call that can fail reports one of these values, alone (kb::Status) or with a value (kb::Result<T>, result.hpp). Ports put a vendor code in the result's Detail().

What happened. Ok is the only success; every other value is a failure.

Enumerator
Ok 

The call did what was asked.

InvalidArgument 

An argument is outside what the call accepts; nothing was done.

OutOfRange 

A value or index does not fit the destination.

Timeout 

The bounded wait ended before the event.

Busy 

The resource is held by someone else; try again.

NotReady 

The object is not started, or not yet able to serve the call.

NoDevice 

Nothing answered at the address (an I2C address NACK, a missing chip).

Nack 

The device refused a data byte.

BusError 

The bus failed: arbitration lost, a stuck line, a framing or parity error.

Overflow 

Data arrived faster than it was consumed, or a result does not fit.

Full 

A fixed-capacity container or queue has no free slot.

Empty 

A container or queue has nothing to take.

Unsupported 

The port or backend does not provide this operation.

AlreadyStarted 

A start was asked of an object that is already started.

CrcMismatch 

A received checksum does not match the data.

Fault 

A failure that no other value describes; Detail() holds the vendor code.
