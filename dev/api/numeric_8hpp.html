Detailed Description

Checked, saturating and range-checked integer arithmetic, free of undefined behaviour.

  • CheckedAdd, CheckedSub, CheckedMul: the exact result in out and true, or false and out unchanged when the result does not fit T.
  • SaturatingAdd, SaturatingSub, SaturatingMul: the exact result, or the nearest limit of T.
  • InRangeCast<To>(from, out): converts only when the value fits; Saturate<To>(from) clamps.

Every function is constexpr and works for every standard integer type except bool and the character types. Arithmetic is done in std::intmax_t or std::uintmax_t after a range check, so no operand is promoted to int and no intermediate overflows.
