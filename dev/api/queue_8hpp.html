Detailed Description

kb::rtos::Queue<T, N>: a static-storage FIFO of N copies of T between threads, with an ISR-safe send.

Items are copied in and out (T is trivially copyable); the item buffer is inside the queue object, so nothing is allocated. Created explicitly with Create(). SendFor and ReceiveFor wait at most their timeout; SendFromIsr() is the only function here an interrupt handler may call.
