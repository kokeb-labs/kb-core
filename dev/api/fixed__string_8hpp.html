Detailed Description

kb::utils::FixedString<N>: a NUL-terminated text buffer of at most N characters, and number formatting into it, with no heap and no printf.

Appends that do not fit are cut at the capacity, set Truncated() and return false; the text stays terminated. Numbers are formatted by the class itself, so no PRId64 or newlib format support is needed.

kb::utils::FixedString<32> line{};
static_cast<void>(line.Append("tick="));
static_cast<void>(line.AppendUnsigned(1234U));
static_cast<void>(line.Append(" status=0x"));
static_cast<void>(line.AppendHex(0x2AU, 2U));
log.Write(line.CStr()); // "tick=1234 status=0x2A"
