Detailed Description

kb::rtos::EventFlags: a group of 24 flags that threads wait on, with an ISR-safe set.

WaitAny(bits, timeout) and WaitAll(bits, timeout) return the flags seen when the wait ended; the wait succeeded when (result & bits) is non-zero (any) or equals bits (all). With clear (the default) the waited flags are cleared on success. Only the low 24 bits are flags (kAllFlags), the portable FreeRTOS width.
