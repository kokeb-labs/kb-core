If this page stays unstyled, it was opened from a file: browsers refuse integrity-checked scripts there. Open offline.html instead, the same configurator in one self-contained file, or serve this folder over http.

Open an existing project

Pick your project's kb-image.yml and, if it has one, its kb-image.lock.yml (both at once). They are read in this browser only: nothing is uploaded or stored, and the address bar gets only catalogue identifiers (not the project's name or drivers this catalogue lacks). The page then shows the project as the selection below and every upgrade the catalogue offers, with the rules of kb upgrade.

The same switch as "Show release candidates" in step 3.

      4 Buses, handlers and thread models

      Wire each driver to a bus; kb-core's handler wraps every driver. Give each bus one thread model (ADR-0009): an owner task that serves every device on it, or a guarded facade that locks around each call.
