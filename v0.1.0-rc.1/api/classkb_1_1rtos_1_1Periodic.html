Detailed Description

A fixed-rate wake-up grid for a periodic loop: Wait(period) returns at start + k * period.

The grid starts at the first Wait() (or Reset()). When a wake-up tick has already passed, Wait() does not block, returns false and counts an overrun; the grid is kept, so a late step does not shift later ones.
